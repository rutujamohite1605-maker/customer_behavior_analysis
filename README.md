# 📊 Customer_Behavior_Analysis

## 📌 Overview

This project demonstrates a complete **Data Analytics Workflow**, transforming raw data into meaningful business insights using Python, SQL, and Power BI.

The project focuses on understanding the dataset, identifying patterns and trends, cleaning and processing data, performing SQL-based analysis, and presenting key findings through an interactive Power BI dashboard.

A detailed analytical report and presentation are also created to communicate the results effectively.

## 🎯 Project Objectives

- Load and explore raw datasets using Python.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess data for accurate analysis.
- Execute SQL queries to extract meaningful insights.
- Build an interactive Power BI dashboard.
- Generate a detailed analytical report.
- Create a professional presentation using Gamma.

## ⚙️ How to Run

### Prerequisites

Install the following tools:

- Python 3.x
- Jupyter Notebook
- PostgreSQL / MySQL / SQL Server
- Power BI Desktop
- Required Python libraries

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Data-Analytics-Project
```

### Step 3: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 4: Run Python Analysis

```bash
jupyter notebook
```

Open the EDA and Data Cleaning notebook and execute the cells.

### Step 5: Perform SQL Analysis

- Create a database using PostgreSQL / MySQL / SQL Server.
- Import the cleaned dataset.
- Open the SQL query file.
- Execute the queries using your database management tool.

### Step 6: Open Power BI Dashboard

- Open Power BI Desktop.
- Load the processed dataset or connect to your database.
- Open the `.pbix` dashboard file.
- Refresh the data if required.

### Step 7: View Reports & Presentation

Open the analytical report and Gamma presentation to review the final findings.
